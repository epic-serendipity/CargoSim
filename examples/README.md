# CargoSim Examples

This directory contains various examples and demonstrations of CargoSim functionality.

## Directory Structure

### `basic/`
Basic usage examples for getting started with CargoSim:
- Simple simulation setup
- Basic configuration examples
- Headless mode usage

### `advanced/`
Advanced feature demonstrations:
- Custom aircraft visual enhancements
- Fleet builder GUI demonstrations
- Advanced configuration scenarios

### `tutorials/`
Step-by-step tutorials:
- Getting started guide
- Configuration walkthrough
- Customization examples

## Running Examples

### Basic Examples
```bash
# Run a basic simulation
python examples/basic/simple_simulation.py

# Run in headless mode
python examples/basic/headless_mode.py
```

### Advanced Examples
```bash
# Custom aircraft visuals demo
python examples/advanced/custom_aircraft.py

# Fleet builder demo
python examples/advanced/fleet_builder_demo.py
```

### Tutorials
```bash
# Getting started tutorial
python examples/tutorials/getting_started.py
```

## Example Categories

### 1. Basic Simulation
- **Purpose**: Learn fundamental CargoSim concepts
- **Audience**: New users and beginners
- **Complexity**: Low to medium

### 2. Advanced Features
- **Purpose**: Explore advanced capabilities
- **Audience**: Experienced users and developers
- **Complexity**: Medium to high

### 3. Tutorials
- **Purpose**: Step-by-step learning
- **Audience**: All users
- **Complexity**: Progressive (starts simple)

## Customization

Each example can be modified to:
- Change simulation parameters
- Adjust visual themes
- Modify fleet configurations
- Test different scenarios

## Contributing

When adding new examples:
1. Place them in the appropriate subdirectory
2. Include clear documentation
3. Add to this README
4. Ensure they work with current CargoSim versions

## Dependencies

Most examples require:
- CargoSim package installed
- Pygame for visualization
- Tkinter for GUI components

For video recording examples, additional dependencies may be required.
